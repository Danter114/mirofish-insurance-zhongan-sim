## 二、数据格式

### 2.1 原始数据 raw（21 字段）

| # | 字段 | 说明 |
| --- | --- | --- |
| 1 | post_id | 全局唯一，格式 `EV{号}_{平台缩写}_{3位序号}` |
| 2 | title | 原帖标题；微博取正文首行前 30 字 |
| 3 | content | 正文全文 |
| 4 | channel | 微博 / 抖音 / 小红书 / 新闻门户 / 黑猫投诉 / 监管通报 |
| 5 | source_platform | 真实来源平台或媒体名（由链接域名映射，映射不到用作者名/渠道名兜底） |
| 6 | event_type | 事件类型，**只能取 8 类枚举之一**（理赔类 / 销售与投保类 / 产品与费率类 / 服务态度类 / 营销类 / 数据与隐私类 / 公司经营类 / 司法与维权类），程序校验强制；体系见桌面《舆情事件分类体系.md》 |
| 7 | post_url | 原帖/原文链接；采集时未记录则为空串 |
| 8 | author_name | 账号昵称或媒体名 |
| 9 | author_uid | 平台内部 ID，可空 |
| 10 | author_fans | 粉丝数，保留原格式，可空 |
| 11 | author_ip_location | IP 归属地，可空 |
| 12 | publish_time | `YYYY-MM-DD HH:MM`；仅日期时补 `00:00` |
| 13-16 | like/comment/repost/collect_cnt | 互动量，平台不显示留 null |
| 17 | is_repost | 是否转载 |
| 18 | keyword_match | 命中检索关键词串 |
| 19 | topic_tag | 事件话题标签 |
| 20 | topic_list | 事件主题词列表 |
| 21 | capture_date | 抓取日期 |

> 评论字段（comments 及其衍生）已从格式中删除；互动量只保留四计数。

### 2.2 处理后数据 processed（28 字段）

= raw 21 字段 + 程序生成 7 字段：

| 字段 | 说明 |
| --- | --- |
| event_id | 事件编号（1~13） |
| role_type | 监管 / 媒体 / KOL / 客户 / 网民 |
| sentiment | 正面 / 中性 / 负面 |
| timespan_days | 距事件 t0 的天数（本库 0~1） |
| is_origin | 是否原帖（false = 转载） |
| event_t0 | 事件首发日 `YYYY-MM-DD` |
| topic_hit / extract_entity | 命中主题词 / 提取实体 |

## 三、口径

### 3.1 渠道（6 类标准口径）

| 渠道 | 口径 |
| --- | --- |
| 微博 / 抖音 / 小红书 | 对应平台原帖 |
| 新闻门户 | **封闭白名单（平台定死，清单外不收录）**：新浪财经、凤凰网、澎湃新闻、界面新闻、蓝鲸财经、财新网、36氪、虎嗅、每日经济新闻、证券时报、第一财经、21世纪经济报道、中国网财经、荔枝网（江苏广电）、中国吉林网、深圳新闻网、腾讯新闻、中华网、金融界、红星资本局、都市快报、新京报、大众日报、上海热线、财联社 |
| 黑猫投诉 | 黑猫投诉平台投诉页 |
| 监管通报 | **封闭白名单（平台定死，权威等级相当于中央发文）**：① 中央部委/监管机构官方渠道（中国政府网、金融监管总局、人民银行、市场监管总局、网信办、沪深交易所）；② 党央媒官方渠道（人民日报、新华社/新华网、央视、央广网、光明日报/光明网、经济日报/中国经济网、中国新闻网、中国网、人民网、中国日报、求是、法制日报，含其转载中央级媒体原文的权威转载）；**白名单外一律不归监管通报**，地方/商业媒体转载中央报道归新闻门户（且媒体本身须在白名单内） |

### 3.2 角色（5 类）

监管 → 媒体 → KOL → 客户 → 网民，命中即停。事件 1-12 沿用参考包判定结果；事件 13 中
监管/媒体/KOL 用规则判定、客户/网民由 LLM 判定（作者本人是否为当事人，正文引语不算）。

### 3.3 情感与标注

- 情感三分类（正面/中性/负面）；**单纯报道或陈述事件、无明显情感色彩的记「中性」**（媒体报道负面事件若只做客观陈述也记中性；有明显负面情感色彩的才记负面）。
- 全部 13 个事件已按统一口径重新标注并写回数据：LLM（deepseek-v4-flash，温度 0）初标 + **口径仲裁层**
  （转述标记→中性 / 标题直接定性→负面 / 客户投诉情绪→负面，见 build_event.py 的 `arbitrate_sentiment`）；
  评测见 `00_程序与文档\情感识别评测报告.md`（口径仲裁后三分类 100%、负面准确率 100%、负面召回率 100%，
  裸 LLM 初标 85.71% 如实披露）；基准集与仲裁清单归档于 `00_程序与文档\评测基准集\`；
- 新事件由 build_event.py 现场调用 LLM 标注并自动走同一口径仲裁。

## 四、build_event.py 使用方法（通用版，任意新事件）

```powershell
# 1. 设置 API 密钥（环境变量，不写入程序）
$env:LLM_API_KEY = "你的密钥"

# 2. 运行（事件号/t0/话题/主题词全部由参数传入，不绑定任何事件）
python build_event.py --raw raw_posts.json --event-id 14 --t0 2026-10-01 `
  --topic-tag "#某事件#" --topic-list 主题词1 主题词2 主题词3 `
  --output event14.json
```

| 参数 | 说明 |
| --- | --- |
| --raw / --output | 输入 raw JSON（21 字段）/ 输出 processed JSON（28 字段） |
| --event-id / --t0 | 事件编号 / 事件起始日 |
| --topic-tag / --topic-list | 话题标签 / 主题词列表（空格分隔） |
| --capture-date | 可选，采集日期 |
| --no-llm | 不调 LLM，用规则兜底（LLM 失败自动重试 2 次，失败清单运行结束打印） |

标注为 4 线程并发调用，结果按 post_id 缓存到 `<output>.cache.json`——重跑秒回、不重复调 API（演示前预热跑一遍即可）。

## 五、舆情看板说明与复现规则

### 5.1 看板包含的 7 个模块

1. **事件概述**（KPI 行：帖子数/窗口/渠道数/主导情感/主要角色）
2. **时间线 / 关键节点**（Day0/Day1 分组，徽标：全网可核验最早·权威转载·网民扩散·待复核）
3. **传播渠道分布**（条形图 + 各渠道具体平台清单 + 渠道×角色矩阵）
4. **情感分布与变化**（情感分段条 + 情感演化曲线：6 小时分桶、三分类三条线、悬停查看各桶数值）
5. **关键词词云**（主题词深灰加粗 / 实体浅灰，字号按频次缩放）
6. **媒体观点分类**（媒体帖按标题措辞与立场分组 + 观点要点）
7. **传播链条**（SVG 四段式：当事人/信源 → 首发 → 转载扩散 → 微博扩散）
外加：顶部静态渠道概览（各渠道帖子数）、帖子明细表（全量，无链接显示「—」）、悬停提示。

### 5.2 设计系统（必须遵守）

- 配色（CSS 变量）：页面 `#fafafa`、卡片 `#ffffff`、主文字 `#111111`、次文字 `#3f3f3f`、说明 `#6e6e6e`、
  边框 `#e2e2e2`、近黑标记 `#1f1f1f`、浅灰轨 `#efefef`、词云主题词 `#141414`/实体 `#6b6b6b`、**蓝色点缀 `#2a78d6`**。
- 蓝色只出现在 7 处：主标题左竖条、模块标题前小方块、渠道概览 chips、时间线关键徽标、Day0 圆点、
  链条 Day0 节点、明细表链接。
- 字体 `system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；正文 14px；KPI 数值 24px/600。
- 图表标记：条形 18px 高、数据端 4px 圆角、值直接标注；圆点 8px 带 2px 表面环；链条箭头 2.5px `#9a9a9a`。
- 单文件、无任何外部依赖、可离线打开。

### 5.3 复现步骤

```
python evt_dash_builder.py <事件目录> <文案包json> <输出html>
```

- 输入 1：`EVT-00N_processed.json`（图表与明细表数据全部来自它，字段见 2.2）；
- 输入 2：`00_程序与文档\看板生成\evt_packs\EVT-00N_pack.json`（叙事性内容：概述/时间线展示文案/
  媒体观点/传播链条节点表，schema 见生成器源码注释，逐事件精修，事实零编造）；
- 输出：`EVT-00N_舆情看板.html`。
- 自检：浏览器打开无报错；渠道概览计数与数据一致；明细表行数 = 数据条数；词云词数 = 主题词数 +
  去重实体数；链条 SVG 全宽渲染。

**命令行方式（等效）**：

## 七、与参考包的差异（摘要）

完整改动明细见桌面《众安舆情_事件1至13_数据改动明细.md》。要点：窗口取 Day0-Day1；
raw 21 字段（新增 source_platform/event_type，删除评论与标注字段）；processed 28 字段
