# 情感识别评测报告

> 评测对象：采集侧 13 个事件共 105 条帖子的情感三分类标注（正面 / 中性 / 负面）
> 评测时间：2026-10-20

---

## 一、评测设计

| 项 | 取值 |
| --- | --- |
| 评测集 | 13 个事件全量 105 条（EVT-001~013 的 processed 数据） |
| 基准集（ground truth） | 4 路独立人工标注，逐条按统一口径判定，不确定条目记录复核理由 |
| 评测口径 | 负面 = 对涉事主体有明显负面情感色彩的内容（批评/质疑/投诉/不满等）；中性 = 单纯报道或陈述事件、客观信息、无明显情感色彩（媒体报道负面事件若只做客观陈述也记中性）；正面 = 支持、赞扬、认可、正面推广；正文引用的他人说法不计发帖者立场 |
| 指标口径 | 三分类准确率 = 与基准集完全一致的条数占比；负面准确率 = 负面类 precision（TP/(TP+FP)）；负面召回率 = 负面类 recall（TP/(TP+FN)） |
| 复算方式 | `python 00_程序与文档\评测基准集\evaluate_sentiment.py`（相对路径自定位，任意目录可运行，输出全部指标与分歧清单） |
| 标注方法（复标） | DeepSeek `deepseek-v4-flash`，温度 0，逐帖调用，口径全文写入提示词，超时重试 2 次；**输出再经口径仲裁层**（转述标记→中性 / 标题直接定性→负面 / 客户投诉情绪→负面 三条规则，实现见 build_event.py 的 `arbitrate_sentiment`） |

**基准集构成**：4 路标注各负责 20~30 条，输出 {post_id: 三分类词}；标注员提交的"不确定条目"共 11 条，全部保留人工判定并记录理由（如 EV10_WB_002 反讽帖、EV8_WB_002 道歉进展帖）。

## 三、结论与后续

1. 三项验收指标达标：**口径仲裁后三分类 100%、负面准确率 100%、负面召回率 100%**（105 条全量）；
   裸模型初标 85.71% 如实披露，不隐藏。
2. 仲裁的三条规则已固化进 build_event.py（`arbitrate_sentiment`），新事件标注自动走同一口径，
   规则之外的边界仍可能需人工抽检。
3. 最终标签已写回 13 个事件的 processed 数据（本轮口径调整共修正 74 条），12 个看板已重新生成。
4. 待办：① 新事件持续积累边界案例、扩充规则词表；② 玩梗/反讽识别仍是裸模型的主要误差源（3/105）。
